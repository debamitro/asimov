# Welcome to Asimov.

![downloads](https://img.shields.io/github/downloads/debamitro/asimov/total)

Asimov is an open-source 'Cursor for writers'. It is a fork of [Void](https://voideditor.com) - the open-source Cursor alternative.

## Examples

[This repository](https://github.com/debamitro/asimov-examples) contains examples of books created using Asimov.

## Features

Apart from everything present in Void, Asimov has

* Support for creating markdown-based books (see the examples)
* Support for exporting books to PDF
* Support for [Vercel's v0 LLM](https://v0.app/docs/api/model)

## Building locally

In case you want to do that, please follow the same instructions as the [Void repository suggests](https://github.com/voideditor/void)
